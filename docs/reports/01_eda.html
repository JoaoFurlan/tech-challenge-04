01 · Primeira exploração do dataset¶

Objetivo. Conhecer o application_train.csv do Home Credit Default Risk: o que ele contém, como está distribuído, onde há problemas e o que se relaciona com a inadimplência. Este notebook só observa: o que se vê aqui vira perguntas e, depois, decisões, mas nenhuma decisão é tomada neste documento.

1. O que é cada linha¶

Cada linha é um pedido de crédito de um cliente (SK_ID_CURR identifica o pedido). A coluna TARGET vale 1 quando o cliente teve dificuldade de pagamento e 0 caso contrário. As demais colunas descrevem o cliente, o pedido e dados externos. Agrupando pelo nome:

def group(c):
    if c in ("SK_ID_CURR", "TARGET"): return "identificação / alvo"
    if c.startswith("EXT_SOURCE"): return "scores externos (EXT_SOURCE_1/2/3)"
    if c.startswith("FLAG_DOCUMENT"): return "documentos entregues (FLAG_DOCUMENT_*)"
    if c.endswith(("_AVG", "_MODE", "_MEDI")) or c == "TOTALAREA_MODE": return "características do imóvel (*_AVG/_MODE/_MEDI)"
    if c.startswith("AMT_REQ_CREDIT_BUREAU"): return "consultas ao bureau (AMT_REQ_CREDIT_BUREAU_*)"
    if "SOCIAL_CIRCLE" in c: return "círculo social (*_SOCIAL_CIRCLE)"
    if c.startswith("AMT_"): return "valores financeiros (AMT_*)"
    if c.startswith("DAYS_"): return "datas relativas em dias (DAYS_*)"
    if c.startswith(("REG_", "LIVE_", "REGION_")): return "região / endereço"
    if c.startswith("FLAG_"): return "indicadores (FLAG_*)"
    return "demais (perfil, contrato, ocupação...)"

3. Dados ausentes¶

Não basta contar nulos: a causa da ausência importa. Três casos clássicos: MCAR (aleatória), MAR (depende de outras variáveis observadas) e MNAR (depende do próprio valor que falta).

7. Correlações e sinais de vazamento (leakage)¶

Vazamento é quando uma coluna contém informação que só existiria depois do resultado, fazendo um modelo parecer melhor do que realmente é. Um sinal clássico: uma única coluna que prevê o alvo quase perfeitamente.

Como é calculado o "poder preditivo isolado": para cada coluna numérica, o valor bruto é usado como se fosse um score, e calcula-se o AUC-ROC contra o alvo, usando só as linhas em que o valor existe (colunas com menos de 1.000 valores são puladas). Depois toma-se max(AUC, 1 − AUC), porque a direção não importa: uma coluna que sobe quando a inadimplência cai dá 0,3, e o 0,7 equivalente é o que interessa. Interpretação: a probabilidade de um inadimplente aleatório ter valor maior (ou menor) que um adimplente aleatório. 0,5 = nenhuma separação. Limitação: enxerga uma coluna por vez e supõe tendência monótona.

num = df.select_dtypes("number").drop(columns=["SK_ID_CURR", "TARGET"]).copy()
num["DAYS_EMPLOYED"] = num["DAYS_EMPLOYED"].replace(DAYS_EMPLOYED_SENTINEL, np.nan)
auc = {}
for c in num:
    v, k = num[c], num[c].notna()
    if k.sum() > 1000 and v[k].nunique() > 1:
        a = roc_auc_score(y[k], v[k])

8. Resumo do que vimos¶

Fatos

  1. 307.511 pedidos × 122 colunas; ≈8% de inadimplentes (desbalanceado).
  2. Sem data absoluta: só datas relativas ao pedido.
  3. 67 colunas têm nulos; 41 têm mais da metade ausente. O bloco do imóvel (47 colunas) some em conjunto e a ausência se associa a mais inadimplência.
  4. Ausências estruturais: OWN_CAR_AGE (sem carro) e o código 365243 em DAYS_EMPLOYED (aposentados/desempregados).
  5. Renda com cauda extrema (até 117 milhões); 4 linhas XNA em gênero.
  6. Sem duplicatas; sem renda nula/≤0 nem idade < 18.
  7. EXT_SOURCE_1/2/3 são os sinais mais fortes (AUC isolado 0,66–0,68); renda, idade e emprego são sinais bem mais fracos; razões financeiras simples quase não se correlacionam.
  8. Sem sinal de vazamento.
  9. Muitas colunas do imóvel são quase redundantes entre si.

Perguntas em aberto

  • Qual é a origem dos EXT_SOURCE e por que faltam em parte dos clientes?
  • A ausência do bloco do imóvel é causa ou apenas marcador de outro perfil de cliente?
  • Como tratar o valor 365243 e a cauda da renda antes de qualquer cálculo?
  • As diferenças por gênero são só estatísticas ou indicam risco de viés a acompanhar?
  • Quanto das 122 colunas realmente agrega, dado o grau de redundância?
